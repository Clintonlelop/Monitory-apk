# Monitory UI Preview

Standalone visual prototype for previewing a redesigned Monitory dashboard in Freebuff.

## Files
- index.html — dashboard structure and sample data
- styles.css — responsive layout, visual styling, subtle animation, auto light/dark theme
- app.js — theme switch, device search, mobile navigation, and preview feedback

## Preview
Open index.html in a modern browser. No npm install or build step is needed.

## Important
This is a visual-only prototype. Counts, device statuses, battery values, activity entries, and system-health values are examples, not live data. No device actions run and no backend is connected.

## Instructions for Freebuff
Use this UI preview as a design reference. Recreate the visual style in the existing Monitory web dashboard while preserving current backend/API endpoints, authentication, routing, element IDs, and JavaScript hooks. Do not replace the full project with this static demo. Default to the device's light/dark appearance and provide a manual theme toggle. Do not modify Android source code or merge into main.
